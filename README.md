# NFSU2DrawAll
A mod for NFSU2 that allows you to display the entire map.
NFSU2DrawAll - This is a mod script that removes the restrictions on stimming the map in the game NFS Underground 2. As a result, you can display the entire map at once using the game engine.

Installation:

! Before installation, make sure that you're using v1.2 speed2.exe (4,57 MB (4.800.512 bytes)).
If not, just search "NFS Underground 2 v1.2 NO CD Crack HOODLUM" on Google, Bing or any search engine you like.

Now you can install. Just follow these steps:

1) Select "dinput8.dll" file and "scripts" folder in the archive. (If dinput8.dll is already installed, you don’t need to change it.)
2) Copy them to your NFSU2 Installation Folder.
3) (Optional) Edit the NFSU2DrawAll.ini file.
4) Launch the game and enjoy the city.
